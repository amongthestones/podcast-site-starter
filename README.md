# Podcast Site Starter

A podcast website built from your RSS feed. No WordPress, no plugin, no database.

**Status:** proof of concept. Not built yet. See the issues for the plan.

## How it will work

1. Deploy to Netlify and paste your podcast's RSS feed URL.
2. The site reads the feed when it builds and makes a page for every episode.
3. A daily rebuild picks up new episodes.

The repo includes a guide for AI coding agents, so you can ask one to restyle or extend the site.

Works with any public podcast RSS feed. Built with Castos-hosted shows in mind.
